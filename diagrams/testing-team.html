The rules that keep testing focused and cheap

One page or flow per handoff. A planner never says "audit the whole app". Small scope means small context and fewer tokens.

Planner and tester are different agents. The one who decides what to test never writes the test, and the one who writes it must run it.

E2E only when a user can see the change. An internal refactor gets a written "no action" verdict instead of a pointless test.

Reuse before create. Tara searches for an existing class, element or helper first, so nothing is written twice.
